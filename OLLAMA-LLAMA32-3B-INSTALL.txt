작업명 : OLLAMA-LLAMA32-3B-INSTALL

✅ 작업 완료 - llama3.2:3b 모델을 동일한 오프라인 manifests+blobs 반입 방식으로 개발 PC에 설치하고, 실제 /api/chat 호출로 추론까지 검증

════════════════════════════════════════════════════════════════════════
1. 요청 요약 / 배경
════════════════════════════════════════════════════════════════════════
- docs/DEPLOYMENT_CHECKLIST.md §6 의 MV_COUNT_MISMATCH_LLM_GUIDE_MODEL 기본값은
  `llama3.2:3b-instruct-q4_K_M` 로 문서화돼 있다. 이번에 개발 PC에 실제 반입한
  태그는 `llama3.2:3b`(instruct-q4_K_M 접미사 없는 기본 태그)이며, 두 태그 문자열이
  다르다 — 동일 계열이지만 문서 기본값과 실제 반입 태그가 일치하는지는 별도 확인이
  필요하다(이번 작업 범위에서는 미확인, 아래 5번 참고).
- gemma3:4b([[OLLAMA-GEMMA-INSTALL]])와 동일한 OLLAMA_MODELS 공유 경로에 반입해
  단일 Ollama 서버가 두 모델을 모두 서빙 가능한 상태로 구성했다.
