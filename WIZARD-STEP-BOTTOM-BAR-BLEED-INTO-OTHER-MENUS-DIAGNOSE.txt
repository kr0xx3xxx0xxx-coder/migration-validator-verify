원인
────────────────────────────────────────────────────────────────────────────
컴포넌트   하단 단계 네비게이션 바 = #mvCmdBar(Compact Command Bar 공통 컴포넌트).
           ui/tabler_renderer.py:3292  <div id="mvCmdBar" class="mv-cmdbar" style="display:none">
           표시/숨김은 mvCommandBarRender(config) 가 담당(ui/tabler_renderer.py:6894)
           — config.visible===false 면 hideCompactCommandBar() 로 display:none 처리.
           개별검증 화면(scope='single-validation')의 config 는
           _mvSingleValidationCmdBarConfig()(ui/tabler_renderer.py:6944)가 만든다 —
           이 함수는 이미 "var onAnalyze = (_mvCurrentTab === 'analyze'); if (!onAnalyze)
           return {visible:false};" 로 '개별검증 탭이 아니면 숨김' 판정을 정확히 하고 있었다.

근본원인   문제는 판정 로직이 아니라 '언제 재평가하는가'였다. 좌측 메뉴 클릭은 전부
           showTab(name)(ui/tabler_renderer.py:7417, Navigation Controller 단일 진입점)를
           거치는데, 이 함수는 SubNav(상단 1~5 단계 탭, _mvHideStepNavBar)는 탭 전환마다
           갱신하면서(7492~7496행) 하단 커맨드바는 단 한 번도 다시 그리지 않았다.
           #mvCmdBar 는 개별검증 화면에서 렌더될 때 bar.style.display=''(인라인 스타일)로
           고정되고, 이후 다른 메뉴로 이동해도 그 인라인 스타일이 그대로 남는다 — DOM 은
           단순히 다른 탭 패널(#tab-settings 등)이 보이는 것뿐이라, 같은 페이지 최하단에
           위치한 #mvCmdBar 는 계속 화면에 그려진 채로 남았다(현재 단계 문구까지 그대로).
           _mvRenderCmdBar() 자체는 존재했고 개별검증 화면 안에서 단계 변경 시에는 호출됐지만
           (6742행 "단계 변경 시 하단 바 갱신"), 메뉴 자체를 벗어나는 호출 경로가 없었다.

재현       실 서비스(포트 8000) 실 브라우저로 재현: 개별검증 진입(쿼리검토 단계, SQL 미입력) →
           좌측 'DB 프로필 / 검증 경로' 클릭 → 하단바 "현재 단계: 쿼리검토 · SQL 미입력 ·
           연결 정상 · ◀ 이전 · 다음 ▶" 가 그대로 잔존, 화면 하단 DB 프로필 목록을 가림
           (screenshot: before_02_settings.png). mvCmdBar computed display='block'
           (기대값 'none'), currentTab='settings' 로 상태 불일치 확인.

파일:라인   ui/tabler_renderer.py:7498~7505 (showTab 함수 말미, SubNav 갱신 블록 직후)

내용       showTab() 종료 직전에 _mvRenderCmdBar() 호출 1줄 추가.
             try { if (typeof _mvRenderCmdBar === 'function') _mvRenderCmdBar(); } catch (e) {}
           SubNav 와 동일한 패턴으로, 탭 전환마다 adapter(_mvSingleValidationCmdBarConfig)가
           '현재 _mvCurrentTab' 기준으로 config 를 새로 계산한다 — 개별검증이 아니면
           visible:false → mvCommandBarRender 가 hideCompactCommandBar() 로 실제 숨김.
           개별검증으로 복귀하면 같은 adapter 가 _singleViewStep 등 기존 진행 상태를
           그대로 다시 읽어 렌더하므로, 숨겼다가 다시 보일 때 단계 상태가 유실되지 않는다.
           판정 로직(_mvSingleValidationCmdBarConfig 자체)은 무접촉 — 호출 시점만 보강.
