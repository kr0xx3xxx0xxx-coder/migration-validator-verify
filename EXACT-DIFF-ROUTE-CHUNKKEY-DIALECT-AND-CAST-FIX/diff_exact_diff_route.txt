    fix(exact-diff): SCOPE 모드 방언 캐스트 분기 + chunk key dialect 배선 (EXACT-DIFF-ROUTE-CHUNKKEY-DIALECT-AND-CAST-FIX)
    
    routes/exact_diff_route.py 의 오라클 전용 차단 2건을 해소한다.
    
    (1) _resolve_key 가 resolve_confirmed_chunk_key 에 dialect 를 넘기지 않아 기본
        postgres 로 렌더됐다 — NULL probe 가 `LIMIT 1` 로 나가 오라클에서 ORA-00933
        으로 실패하고, _has_null=None → confirm_chunk_key=None → 키 ("","") → 사유
        없는 조용한 HOLD 로 떨어졌다. 접속 db_type 을 공통 헬퍼(_to_sqlglot_dialect)
        로 도출해 전달한다(혼합 방언은 기존대로 postgres 유지).
    
    (2) SCOPE 모드가 PG 전용 `::text` 캐스트와 밑줄 선두 별칭 `__sf` 를 써서 오라클
        에서 실행 자체가 불가능했다(`:text` 바인드 변수 오인 DPY-4010 / ORA-00911).
        캐스트를 _scope_eq_expr 로 4개 방언 모두 분기하고(oracle=TO_CHAR, mysql=CAST
        AS CHAR, mssql=CAST AS NVARCHAR, postgres=기존 ::text 유지), 별칭을 문자로
        시작하는 mv_scope_src / mv_scope_tgt 로 개명했다.
    
    UI 는 전체>5만 & scope<=5만 일 때 SCOPE 를 보내므로(tabler_renderer.py:16549)
    오라클 XDIFF 25만행에서 실제로 도달하는 경로다. PG 는 술어 표현 무변경(별칭명만
    변경)이라 회귀 없음.
