STAGE5-EXTRACT-STATUS-TRACKING-BUG-AND-SUMMARY-LAYOUT-FIX.md(직전 지침, 완료됐으면

────────────────────────────────────────────────────────────
1. 헤더 라벨 — 원본/목적 구분 명시 + 한글 컬럼명 위치
────────────────────────────────────────────────────────────
현재 상세 레코드 테이블 헤더가 같은 컬럼명(예: REGION_CD)이 원본/목적 두 번 나오는데
어느 쪽이 원본이고 어느 쪽이 목적인지 헤더만 봐서는 구분이 안 된다.

수정:
- 헤더를 "REGION_CD(목적)" / "REGION_CD(원본)" 형태로, 컬럼명 뒤에 (목적)/(원본)을
  명시.
- 각 컬럼 헤더 하단에 그 컬럼의 한글 컬럼명(코멘트/한글명이 있으면)을 작게 배치.
  한글명을 새로 조회하지 말고 이미 메타데이터로 갖고 있는 값(다른 화면에서 이미
  쓰고 있는 한글 컬럼명 소스)을 재사용해라.

────────────────────────────────────────────────────────────
2. 그리드 색상 원복 — 흰색으로
────────────────────────────────────────────────────────────
현재 상세 레코드 테이블 행에 옅은 색(민트/연두 계열로 보임)이 배경으로 깔려있다.
이걸 일반 흰색 배경으로 되돌려라(불일치 값 강조 등 의미 있는 색상 표시가 따로
있다면 그건 유지하고, 행 전체를 덮는 배경색만 제거).

────────────────────────────────────────────────────────────
3. 그룹 펼침 영역의 중복 검색조건 폼 제거
────────────────────────────────────────────────────────────
배경(스크린샷 근거): 그룹을 펼쳤을 때 안에 "불일치 유형/GROUP BY 기준/그룹 값/PK 검색"
검색조건 폼이 뜨는데, 이미 특정 그룹(예: STATUS_CD=G01) 안에 들어와 있는 상태이므로
"GROUP BY 기준: 전체"/"그룹 값: 전체" 같은 선택지는 의미가 없다(이미 그 그룹으로
좁혀진 뒤인데 "전체 중에서 골라라"는 옵션이 다시 뜨는 모순). 이건 M56 이전(전체
결과를 한 화면에서 검색·필터링하던 옛 방식)의 검색 폼이 새 아코디언 구조로 안 바뀌고
남아있는 잔재로 보인다.

수정: "GROUP BY 기준"/"그룹 값" 드롭다운은 제거. "불일치 유형" 필터와 "PK 검색"만
남길지, 그것도 필요 없다고 판단되면 함께 제거할지는 실제 코드를 보고 이 필터들이
프론트엔드에서 별도 API 호출 없이 이미 로드된 데이터를 걸러내는 용도인지 확인한 뒤
판단해도 된다(살릴 가치가 있으면 남기고, 마찬가지로 옛 화면 잔재면 함께 제거).
