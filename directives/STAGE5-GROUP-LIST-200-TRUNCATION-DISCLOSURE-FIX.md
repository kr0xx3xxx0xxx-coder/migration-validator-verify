## 배경 (BACKLOG.md M82 I-3)
5단계 그룹 목록이 서버 `MAX_DISPLAY_ROWS=200`(`stats_execute_service.py:34,
661-663`)으로 절단된 상태로 만들어진다. 불일치 그룹이 200개를 넘으면
201번째부터 드릴다운 진입점 자체가 화면에서 사라지는데, 화면엔 "불일치그룹
N개" 라는 확정된 것처럼 보이는 문구만 뜨고 절단됐다는 고지가 전혀 없다.

## 작업 범위 - `stats_execute_service.py`만 수정할 것 (프론트 표시 문구
   변경이 필요하면 그 파일도 명시적으로 알려줄 것, 임의로 다른 파일 건들지
   말 것)
1. 절단 로직 자체(200건 상한)는 그대로 유지 - 상한값 변경은 이번 지침
   범위 밖(성능/부하 판단 필요, 별도 결정 사항).
2. 실제 불일치 그룹 수가 200을 초과하는 경우, 화면에 "불일치그룹 N개(상위
   200개만 표시, 나머지 M개는 절단됨)" 같은 형태로 정직하게 고지되도록
   수정. 정확한 문구는 기존 유사 절단고지 패턴(있다면)을 찾아서 재사용.
3. 200개 이하인 정상 케이스는 기존 문구 그대로 유지(불필요한 변경 금지).

## 검증 (필수)
- 서버 최신 코드 서빙 여부 확인 후 검증.
- 200개 초과 케이스를 실제로 만들어(픽스처로 재현) 절단 고지 문구가
  실브라우저에 뜨는지 확인.
- 200개 이하 정상 케이스에서 문구 변화 없는지(회귀 없음) 확인.
