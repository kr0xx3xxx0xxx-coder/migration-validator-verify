작업명 : STAGE5-MISMATCH-LIST-HEADER-TEXT-FIX

배경: 5단계 불일치 리스트 표 위쪽 헤더 문구 "전체 재이관 대상(이 그룹) 101건"을
"전체 재이관 대상 : 101건"으로 바꿔달라는 요청.

────────────────────────────────────────────────────────────
구현
────────────────────────────────────────────────────────────
이 문구를 그리는 코드를 찾아서, "전체 재이관 대상(이 그룹) N건" 형식을
"전체 재이관 대상 : N건" 형식으로 바꿔라 — 건수(N) 계산 로직은 그대로 두고
문구 포맷만 바꿔라.

────────────────────────────────────────────────────────────
검증(필수, 실제 클릭)
────────────────────────────────────────────────────────────
- 실제 화면에서 문구가 "전체 재이관 대상 : 101건" 형태로 바뀌었는지, 건수 값
  자체는 정확한지 확인.
- 스크린샷 포함.
- 관련 테스트 서브셋 + baseline 대조, 신규 회귀 0건.
- CLAUDE.md 필수 회귀(virtual/complex) 최종 1회.
- 완료보고: 파일:라인, 검증 결과, 커밋해시. 작업명 첫줄/마지막줄. 코드 변경이
  있으니 서버 재기동 필수, 재기동 시각·HEAD 커밋 해시 명시.
