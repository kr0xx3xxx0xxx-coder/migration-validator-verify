작업명 : MATCHED-ROWS-TOGGLE-MISSING-IN-COMBO-CASE-DIAGNOSE

배경(스크린샷 근거): M87에서 "일치 행 보기 (N건)" 토글이 이미 존재하고 정상
작동한다고 확인했었다(당시 8그룹, 3불일치+5일치 소규모 픽스처로 실측). 그런데
지금 사용자가 실제로 쓰는 화면(NXDNP.MV_SCATTER50M, 조합축 포함, 전체그룹 236개
· 불일치그룹 21개)에는 "불일치 그룹 21개 · 상세 추출 완료 0개" 문구와 표만
있고, 화면 맨 아래(검증 그룹에 등록 섹션 아래)까지 스크롤해도 "일치 행 보기"
토글이 전혀 보이지 않는다.

조사 항목
────────────────────────────────────────────────────────────
1. "일치 행 보기" 토글이 렌더되는 정확한 조건을 코드로 다시 확인해라 — M87이
   확인했던 소규모 단순 케이스와 지금 이 케이스(조합축 포함 다중세트, 전체
   236개 중 불일치 21개)의 차이가 무엇인지 비교해라.
2. 다음 가능성들을 각각 확인해라:
   - 조합축(다중 GROUP BY 세트)이 섞이면 이 토글 자체가 다른 렌더 경로를
     타서 토글이 아예 안 만들어지는 구조인지
   - 토글은 만들어지는데 화면 어딘가 다른 위치(예: 각 세트별로 개별 존재)
     흩어져 있어서 사용자가 못 찾은 것뿐인지
   - 규모(그룹 236개)가 크면 토글 자체를 의도적으로 숨기는 조건이 있는지
3. 실제로 재현해라 — 지금 화면과 동일한 조건(조합축 포함, NXDNP.MV_SCATTER50M
   또는 유사 규모)으로 개별검증을 돌려서, 토글이 진짜로 안 뜨는지 실측
   확인해라.
