작업명 : OLLAMA-GEMMA-INSTALL

코드 저장소 파일은 건드리지 않는다 — 순수 시스템 설치 작업. Ollama가 이 PC에
미설치 상태임을 이미 확인했다(OLLAMA-INSTALL-STATUS-CHECK 채팅 조사).

배경: E1(COUNT 불일치 원인 가이드) LLM 연동을 위해 Ollama를 설치하고, Google의
Gemma 3 4B 모델을 받는다. 오픈소스·자체호스팅·폐쇄망 안전·비중국계 요구사항을
만족하는 모델로 선정됨.

────────────────────────────────────────────────────────────
0. 설치 드라이브 결정 — 확정됨(사용자 결정 완료)
────────────────────────────────────────────────────────────
**모델 저장 위치는 `X:\Projects\_shared\ollama\`로 확정한다** — 더 이상 논의
필요 없음, 이 경로 그대로 써라:
- `X:\Projects\` 안에 두되, `nxDTV` 프로젝트 폴더 안에 넣지 않고 형제 폴더
  (`_shared`)로 분리한다 — 나중에 다른 프로젝트가 생겨도 같은 Ollama 서비스와
  모델을 재사용할 수 있게 하기 위함(공유 인프라 성격 명시).
- `OLLAMA_MODELS` 환경변수를 `X:\Projects\_shared\ollama\`로 지정해서 설치해라.
- 디렉터리가 없으면 새로 만들어라.

────────────────────────────────────────────────────────────
구현
────────────────────────────────────────────────────────────
1. Ollama를 Windows용 공식 설치 파일로 설치해라(https://ollama.com/download 에서
   받거나, 이미 알고 있는 안전한 설치 방법을 써라).
2. 설치 후 Ollama 서비스가 정상 기동되는지 확인해라(포트 11434 LISTEN).
3. `ollama pull gemma3:4b`로 모델을 받아라.
4. 간단한 프롬프트로 실제 응답이 오는지 테스트해라(예: `ollama run gemma3:4b
   "안녕하세요"` — 한국어 응답이 정상적으로 오는지 확인).

────────────────────────────────────────────────────────────
검증(필수)
────────────────────────────────────────────────────────────
- `ollama list`로 gemma3:4b가 실제로 설치됐는지 확인.
- 포트 11434가 정상 LISTEN 중인지 확인.
- 한국어 프롬프트에 한국어로 자연스럽게 응답하는지 실제 테스트.
- OpenAI 호환 API 엔드포인트(`http://localhost:11434/v1/...` 또는 Ollama 자체
  API `http://localhost:11434/api/generate`)로 실제 HTTP 요청을 보내서 응답이
  오는지 확인해라(E1 작업이 나중에 이 엔드포인트를 호출할 것이므로, 지금 그
  경로가 실제로 동작하는지 미리 확인해두면 좋다).

완료보고: 설치 결과, 모델 다운로드 확인, 한국어 응답 테스트 결과(실제 프롬프트와
응답 예시 포함), API 엔드포인트 동작 확인. 코드 저장소 변경 없음.

────────────────────────────────────────────────────────────
5. 고객사(폐쇄망) 배포 준비 — 이 PC 설치가 끝난 뒤 이어서 (사용자 추가 요청)
────────────────────────────────────────────────────────────
이번 설치는 개발 PC용이다. **실제로는 고객사(폐쇄망 환경)에도 같은 걸 설치해야
한다.** 폐쇄망이라 그쪽에서 `ollama pull`로 인터넷을 통해 모델을 직접 받을 수
없다 — 반드시 오프라인 반입 절차가 필요하다.

- 이 PC에서 받은 Ollama 설치파일·Gemma 3 4B 모델 파일을 오프라인으로 반입 가능한
  형태(설치 파일 원본 + 모델 blob 파일들의 정확한 경로와 크기)로 정리해라.
- Ollama가 오프라인 환경에서 모델을 등록하는 공식 방법(모델 파일을 특정 경로에
  두고 `ollama list`가 인식하게 만드는 절차, 또는 `Modelfile`을 이용한 로컬 임포트
  방법)을 확인해서 문서로 정리해라.
- M50 설계문서가 이미 언급한 대로, `docs/DEPLOYMENT_CHECKLIST.md`에 "자체 호스팅
  LLM(Ollama) 서빙" 섹션을 신설해서: (a) 오프라인 설치 절차 (b) 모델 반입 방법
  (c) 프로젝트 종료 시 완전삭제 절차(설치 파일·모델·캐시 전부 지우는 방법, M50이
  이미 이 제약을 명시했다) 세 가지를 명확히 적어라.
- 이건 문서 작업이라 코드 저장소(`X:\Projects\nxDTV`)에 문서 파일 하나만 추가하는
  정도로 마쳐라 — 실제로 고객사에 가서 설치하는 건 이번 작업 범위가 아니다.

완료보고에 이 5번 항목 결과(문서 경로, 정리된 오프라인 반입 절차)도 포함해라.
