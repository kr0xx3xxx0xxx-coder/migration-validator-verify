작업명 : OLLAMA-GEMMA-INSTALL

코드 저장소 파일은 건드리지 않는다(5번 문서 작업 제외) — 대부분 순수 시스템
설치 작업. Ollama가 이 PC에 미설치 상태임을 이미 확인했다(채팅 조사로 확인,
명령어·프로세스·포트·설치경로 3곳 모두 없음).

배경: E1(COUNT 불일치 원인 가이드) LLM 연동을 위해 Ollama를 설치하고, Google의
Gemma 3 4B 모델을 받는다. 오픈소스·자체호스팅·폐쇄망 안전·비중국계 요구사항을
만족하는 모델로 선정됨(중국계 모델인 Qwen/DeepSeek/GLM/Kimi 등은 절대 쓰지 마라).

────────────────────────────────────────────────────────────
0. 설치 경로 — 확정됨 (더 이상 논의 필요 없음, 이 경로 그대로 써라)
────────────────────────────────────────────────────────────
**모델 저장 위치: `X:\Projects\_shared\ollama\`**
- `X:\Projects\` 안에 두되, `nxDTV` 프로젝트 폴더 안에는 넣지 않고 형제 폴더
  (`_shared`)로 분리한다 — Ollama는 "nxDTV 전용"이 아니라 여러 프로젝트가 공유할
  수 있는 인프라 성격이기 때문(나중에 다른 프로젝트가 같은 Ollama 서비스·모델을
  재사용할 수 있게).
- `OLLAMA_MODELS` 환경변수를 `X:\Projects\_shared\ollama\`로 지정해서 설치해라.
  디렉터리가 없으면 새로 만들어라.
- Ollama 애플리케이션 자체(실행파일)는 통상 C드라이브 사용자별 경로에 설치될
  수 있다 — 이건 정상이니 그대로 둬라. 모델 저장 위치만 위 경로로 지정하면 된다.
- `X:\Projects\_shared\` 안에 짧은 `README.md`를 하나 만들어서, 이 폴더가
  "여러 프로젝트가 공유하는 인프라용(현재는 Ollama만)"이라는 걸 한두 줄로
  남겨라 — 나중에 이 폴더를 처음 보는 사람이 용도를 바로 알 수 있게.

────────────────────────────────────────────────────────────
1. Ollama 설치 + 모델 다운로드
────────────────────────────────────────────────────────────
1. Ollama를 Windows용 공식 설치 파일로 설치해라(https://ollama.com/download).
2. 설치 후 서비스가 정상 기동되는지 확인해라(포트 11434 LISTEN).
3. `ollama pull gemma3:4b`로 모델을 받아라(0번에서 지정한 경로에 저장되는지 확인).
4. `ollama run gemma3:4b "안녕하세요"` 같은 한국어 프롬프트로 실제 응답을 테스트해라
   — 자연스러운 한국어로 응답하는지 확인.

────────────────────────────────────────────────────────────
2. API 엔드포인트 동작 확인
────────────────────────────────────────────────────────────
OpenAI 호환 API(`http://localhost:11434/v1/...`) 또는 Ollama 자체 API
(`http://localhost:11434/api/generate`)로 실제 HTTP 요청을 보내서 응답이 오는지
확인해라 — E1 작업이 나중에 이 엔드포인트를 호출할 것이므로 미리 확인해두면 좋다.

────────────────────────────────────────────────────────────
3. 고객사(폐쇄망) 배포 준비 — 문서화
────────────────────────────────────────────────────────────
이번 설치는 개발 PC용이다. **실제로는 고객사(폐쇄망 환경)에도 같은 걸 설치해야
한다.** 폐쇄망이라 그쪽에서 `ollama pull`로 인터넷을 통해 모델을 직접 받을 수
없다 — 반드시 오프라인 반입 절차가 필요하다.
- 이 PC에서 받은 Ollama 설치파일·Gemma 3 4B 모델 파일을 오프라인으로 반입 가능한
  형태(설치 파일 원본 + 모델 blob 파일들의 정확한 경로와 크기)로 정리해라.
- Ollama가 오프라인 환경에서 모델을 등록하는 공식 방법(모델 파일을 특정 경로에
  두고 `ollama list`가 인식하게 만드는 절차, 또는 `Modelfile`을 이용한 로컬 임포트
  방법)을 확인해서 문서로 정리해라.
- M50 설계문서가 이미 언급한 대로, `docs/DEPLOYMENT_CHECKLIST.md`에 "자체 호스팅
  LLM(Ollama) 서빙" 섹션을 신설해서: (a) 오프라인 설치 절차 (b) 모델 반입 방법
  (c) 프로젝트 종료 시 완전삭제 절차(설치 파일·모델·캐시 전부 지우는 방법) 세
  가지를 명확히 적어라.
- 이건 코드 저장소(`X:\Projects\nxDTV`)에 문서 파일 하나만 추가하는 정도로
  마쳐라 — 실제로 고객사에 가서 설치하는 건 이번 작업 범위가 아니다.
