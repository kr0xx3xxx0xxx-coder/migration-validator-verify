작업명 : OLLAMA-LLAMA32-3B-INSTALL

**주의: SHARED-FOLDER-OLLAMA-FILES-ORGANIZE가 같은 폴더(X:\Projects\_shared\ollama\)
를 정리하고 있을 수 있다. 시작 전 그 작업이 완료됐는지 확인하고, 아직 진행 중이면
끝날 때까지 기다렸다가 시작해라.**

OLLAMA-GEMMA-INSTALL.txt(오늘 완료된 Ollama+Gemma 설치)를 먼저 읽고 시작해줘.
Ollama 자체는 이미 설치돼 있으니 재설치하지 마라 — 이번엔 Meta의 Llama 3.2 3B
모델만 추가로 받는다.

배경: Gemma 3 4B와 비슷한 체급의 Meta Llama 3.2 3B를 추가로 받아서, 같은 조건
(E1 COUNT 불일치 안내문 생성)에서 두 모델의 한국어 품질을 비교할 수 있게 한다.

────────────────────────────────────────────────────────────
구현
────────────────────────────────────────────────────────────
1. `OLLAMA_MODELS` 환경변수가 이미 `X:\Projects\_shared\ollama\`로 설정돼 있는지
   확인해라(오늘 이미 설정됨 — 재설정 불필요, 확인만).
2. `ollama pull llama3.2:3b`로 모델을 받아라.
3. `ollama run llama3.2:3b "안녕하세요"` 같은 한국어 프롬프트로 실제 응답을
   테스트해라 — 자연스러운 한국어로 응답하는지 확인.
4. API 엔드포인트(`http://localhost:11434/api/generate` 등)로 실제 HTTP 요청을
   보내서 `llama3.2:3b`를 모델로 지정했을 때 정상 응답이 오는지 확인해라.

────────────────────────────────────────────────────────────
검증(필수)
────────────────────────────────────────────────────────────
- `ollama list`로 `gemma3:4b`와 `llama3.2:3b` 둘 다 `X:\Projects\_shared\ollama\`에
  저장돼 있는지 확인(두 모델 공존 확인).
- 한국어 프롬프트 응답 테스트 결과(실제 프롬프트·응답 예시 포함) — 가능하면 같은
  프롬프트로 Gemma 3 4B와 Llama 3.2 3B 응답을 나란히 비교해서 완료보고에 둘 다
  남겨라(간단한 참고용 비교, 정밀 벤치마크까지는 필요 없음).
- API 엔드포인트 정상 동작 확인.
- 기존 Gemma 3 4B 설치·E1 연동에 전혀 영향 없는지(둘 다 같은 Ollama 서버에서
  모델만 바뀌는 구조이므로) 확인.

완료보고: 설치 결과, 한국어 응답 테스트(Gemma와 비교), API 확인. 코드 저장소
변경 없음.
