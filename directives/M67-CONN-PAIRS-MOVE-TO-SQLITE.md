작업명 : M67-CONN-PAIRS-MOVE-TO-SQLITE

DB-CONNECTION-PROFILE-LOSS-ON-RESTART-DIAGNOSE.txt를 먼저 읽고 시작해줘. 승인 완료.
M67의 개선안 3번(구조변경) 중 "검증 경로(Pair)"에 한정된 부분만 진행한다 — 활성
접속상태 재검증 로직과 프로젝트 선택 재검증 로직은 이번 범위에서 안 건드린다(그건
의도된 안전설계로 이미 확인됨).

배경: "검증 경로"(원본→목적 DB 조합, `mv_conn_pairs`)가 브라우저 localStorage에만
저장돼 있어, 브라우저 저장소가 사라지는 모든 상황(시크릿모드 창 종료, 캐시 삭제,
다른 브라우저/PC 사용 등)에서 사용자가 애써 만든 조합이 통째로 사라진다. 개별 DB
접속정보(host/id/pw)는 이미 SQLite `mv_db_preset`에 안전하게 저장돼 있으니, 같은
방식으로 Pair도 서버에 영속 저장하자는 것이 이번 지침의 방향이다.

────────────────────────────────────────────────────────────
구현
────────────────────────────────────────────────────────────
1. 신규 SQLite 테이블(예: `mv_conn_pair`)에 Pair 정보(연결 이름, 원본 DB 프로필
   참조, 목적지 DB 프로필 참조, 생성일 등 — 비밀번호/host 등 민감정보는 이미
   `mv_db_preset`이 별도로 갖고 있으니 여기선 참조(FK)만) 저장하는 서비스/라우트
   신설. 기존 `mv_db_preset` 저장 패턴을 최대한 재사용해라(새 저장 프레임워크
   발명 금지).

   **중요: 원본/목적 프로필 하나가 여러 조합(Pair)에 동시에 쓰일 수 있어야 한다**
   (예: Oracle_asis가 "Oracle_asis→Oracle_tobe"와 "Oracle_asis→PostgreSQL_tobe"
   두 조합 모두에서 원본으로 재사용). 원본참조/목적참조 컬럼 각각에 개별 UNIQUE
   제약을 걸지 마라 — 같은 프로필 ID가 여러 행에 원본 또는 목적으로 반복 등장하는
   걸 막으면 안 된다. 다만 "정확히 같은 원본+목적 조합"이 완전히 중복 저장되는
   것까지 막을지는 판단해서 처리해도 된다(둘 다 같은 (원본ID, 목적ID) 쌍인 완전
   중복 행 방지 정도는 무방, 그 외 제약은 걸지 말 것).
2. 프론트엔드가 페이지 로드 시 이 신규 API로 Pair 목록을 조회해서 그리도록 배선.
   기존 `mv_conn_pairs`(localStorage) 읽기/쓰기 로직을 신규 API 호출로 교체.
3. PostgreSQL 기본 Pair 하드코딩(`_defaultPairs()`)은 그대로 유지해도 되고, 이제
   서버에 진짜 저장되는 Pair들과 섞여도 자연스럽게 동작하는지 확인해라(중복 표시
   등 회귀 없게).
4. 기존에 localStorage에 남아있는 Pair가 있다면(마이그레이션 대상), 최초 로드 시
   1회 서버로 옮겨주는 것까지는 이번 범위가 아니다(사용자가 다시 만들면 됨) —
   과설계 금지, 단순 전환.

────────────────────────────────────────────────────────────
검증(필수, 실제 클릭)
────────────────────────────────────────────────────────────
- Pair를 새로 만들고, 브라우저 시크릿창을 완전히 닫았다가 새로 열어서(localStorage
  확실히 소거되는 상황) 다시 접속했을 때 그 Pair가 그대로 남아있는지 확인.
- 서버 재기동 후에도 남아있는지 확인.
- **같은 원본 프로필(예: Oracle_asis)로 서로 다른 목적지 2개(Oracle_tobe,
  PostgreSQL_tobe)를 각각 조합해서 Pair 2개를 만들고, 둘 다 정상적으로 저장·
  조회되는지 실제 클릭으로 확인**(다대다 지원 검증).
- 활성 접속(접속중) 재검증 로직은 기존과 동일하게 작동하는지(이번 범위 아니므로
  회귀 없어야 함) 확인.
- 관련 테스트 서브셋 + baseline 대조, 신규 회귀 0건.
