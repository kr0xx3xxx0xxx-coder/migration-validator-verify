작업명 : MATCHED-GROUPS-VISIBILITY-AND-EXCEL-EXPORT-CHECK

코드 수정 없이 조사·실측만 해줘.

배경: M84(완전일치 시 하단표 오표시)는 "불일치 0건(100% 일치)"인 경우만
다뤘다. 사용자가 다른 질문 두 가지를 했다:
1. "불일치그룹이 있으면 일치그룹도 있을 텐데(예: 전체 31개 중 11개만 불일치면
   나머지 20개는 일치), 이 일치 그룹들을 화면에서 볼 방법이 있는가?"
2. "결과를 엑셀 형태로 뽑을 수 있어야 할 것 같다 — 지금 그런 기능이 있는가?"

────────────────────────────────────────────────────────────
1. 일치 그룹 조회 가능 여부 확인
────────────────────────────────────────────────────────────
- M84 조사에서 "일치 행 보기 (N건)" 토글이 존재한다는 언급이 있었다 — 이게
  "전부 일치(0건 불일치)" 케이스 전용인지, 아니면 "일부만 불일치"인 일반적인
  케이스(예: 31개 중 11개 불일치)에서도 나머지 20개 일치 그룹을 볼 수 있게
  해주는 기능인지 명확히 확인해라.
- 실제로 일부만 불일치인 케이스(오늘 하루 종일 쓴 MV_SCATTER50M 등 기존
  픽스처 재사용 가능)에서, 일치한 20개 그룹을 실제로 화면에서 찾아서 볼 수
  있는지 실측으로 확인해라 — 있다면 어디서/어떻게 보는지 스크린샷으로 남겨라.
- 없다면, 서버가 애초에 일치 그룹의 데이터를 갖고 있기는 한지(단순히 화면에
  안 보여주는 것뿐인지, 아니면 처음부터 불일치만 계산하고 일치분은 계산 자체를
  안 하는지) 확인해라.

────────────────────────────────────────────────────────────
2. 엑셀 추출 기능 확인
────────────────────────────────────────────────────────────
- 현재 5단계(또는 다른 단계)에 결과를 엑셀/CSV 등으로 내보내는 기능이 이미
  있는지 확인해라(오늘 초반 대화에서 "Excel 다운로드" 관련 죽은 링크를 제거한
  적이 있는데, 그게 이 기능의 잔재인지도 확인해라).
- 있다면 정상 작동하는지 실측 확인, 없다면 없다고 명확히 답해라.
- 있다면 그 내보내기가 불일치 그룹만 포함하는지, 일치 그룹도 포함할 수 있는지
  확인해라.

────────────────────────────────────────────────────────────
완료보고
────────────────────────────────────────────────────────────
- 1번: 일치 그룹 조회 가능 여부(실측 스크린샷 포함), 안 되면 이유.
- 2번: 엑셀 추출 기능 존재 여부, 있다면 작동 확인, 범위(일치/불일치 포함 여부).
- 코드 수정 없음. 작업명 첫줄/마지막줄.
