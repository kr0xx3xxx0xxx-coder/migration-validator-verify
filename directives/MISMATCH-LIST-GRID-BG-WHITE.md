작업명 : MISMATCH-LIST-GRID-BG-WHITE

간단한 스타일 수정이다 — 테스트/회귀 절차 생략, 확인만 하고 끝내라.

배경(스크린샷 근거): 5단계 불일치 리스트 그리드(PK_STR/REGION_CD/STATUS_CD/
AMT/QTY 표)의 행 바탕색(홀짝 줄무늬 배경 등)을 전부 흰색으로 바꿔달라는 요청.

────────────────────────────────────────────────────────────
구현
────────────────────────────────────────────────────────────
이 그리드의 행 배경색을 전부 흰색(#ffffff)으로 통일해라 — 홀짝 줄무늬(zebra
striping)나 다른 배경색이 적용돼 있으면 제거해라.

────────────────────────────────────────────────────────────
검증(가볍게)
────────────────────────────────────────────────────────────
- 실제 화면에서 배경이 흰색으로 바뀐 걸 스크린샷으로 확인만 해라.
- 전체 테스트/회귀는 생략해도 된다(사용자 명시 지시).
- 완료보고: 파일:라인, 전/후 스크린샷, 커밋해시. 작업명 첫줄/마지막줄. 코드
  변경이 있으니 서버 재기동은 하고, 재기동 시각·HEAD 커밋 해시만 남겨라.
