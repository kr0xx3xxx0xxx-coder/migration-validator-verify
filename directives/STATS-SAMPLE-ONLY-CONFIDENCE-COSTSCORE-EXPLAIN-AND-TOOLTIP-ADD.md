작업명 : STATS-SAMPLE-ONLY-CONFIDENCE-COSTSCORE-EXPLAIN-AND-TOOLTIP-ADD

배경(사용자 화면 근거): 4단계 화면에 "전략 표본 집계 STATS_SAMPLE_ONLY · 신뢰도
HIGH · 규모 초대형 · 예상 그룹 31개 · 예상 스캔 50,000,000행 · 비용점수 16.67 ·
예상 소요 1분 7초"가 표시됐다. 사용자가 "신뢰도"와 "비용점수"가 정확히 뭘 뜻하는지
물었고, "STATS_SAMPLE_ONLY" 전략명 옆에 설명을 추가해달라고 요청했다.

────────────────────────────────────────────────────────────
1. 조사 (먼저)
────────────────────────────────────────────────────────────
- "STATS_SAMPLE_ONLY" 전략이 정확히 뭘 하는 전략인지 확인해라(표본만 집계해서
  통계를 추정하는 방식으로 추정되는데, 정확한 동작을 코드로 확인해라).
- 이 화면의 "신뢰도"(HIGH)가 오늘 확인한 M77의 신뢰도(벤치마크 외삽 배율 기반
  LOW/MEDIUM/HIGH)와 같은 개념인지, 아니면 표본 집계 특유의 다른 신뢰도
  개념(예: 표본 크기 대비 통계적 신뢰구간)인지 확인해라.
- "비용점수"(16.67)가 정확히 어떻게 계산되는 값인지, 단위가 뭔지(초당 비용?
  상대 점수?), 이 숫자가 실제로 어디에 쓰이는지(전략 선택 판정에 영향을
  주는지, 아니면 참고용 표시일 뿐인지) 확인해라.

────────────────────────────────────────────────────────────
2. 구현 — STATS_SAMPLE_ONLY 옆에 설명 추가
────────────────────────────────────────────────────────────
전략명 "STATS_SAMPLE_ONLY" 옆에, 이게 무엇을 하는 전략인지 짧게 설명하는 텍스트
또는 툴팁을 추가해라(예: "(전체를 다 스캔하지 않고 일부 표본만으로 집계를
추정하는 전략)" 같은 한 줄 설명 — 조사 결과에 맞게 정확한 문구로 작성해라).
기존 다른 전략들(DIRECT_STREAM_COMPARE 등)에 유사한 설명이 이미 붙어있는
패턴이 있으면 그 패턴을 그대로 따라라.

────────────────────────────────────────────────────────────
검증(필수, 실제 클릭)
────────────────────────────────────────────────────────────
- 실제 화면에서 STATS_SAMPLE_ONLY 전략이 뜨는 케이스를 재현해서, 설명이
  정확히 표시되는지 스크린샷으로 확인해라.
- 관련 테스트 서브셋 + baseline 대조, 신규 회귀 0건.
- CLAUDE.md 필수 회귀(virtual/complex) 최종 1회.
- 완료보고: 1번 조사 결과(신뢰도·비용점수 정확한 의미와 계산식, 파일:라인),
  2번 구현 결과, 커밋해시. 작업명 첫줄/마지막줄. 코드 변경이 있으니 서버
  재기동 필수, 재기동 시각·HEAD 커밋 해시 명시.
