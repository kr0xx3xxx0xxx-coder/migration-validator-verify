■ 지시서 대비 구현 방식 차이(중요 — 반드시 명시)

  지시서 §3-2 원안: "같은 이름으로 재바인딩 `_select_direct_rep_axis = pc.select_deterministic_rep_axis`
  (pc 는 이미 337행에서 쓰는 기존 alias 그대로 재사용 — 신규 import 금지)".

  실 코드 확인 결과, 337행의 `pc` alias(`from services.exact_diff import pk_range_chunk as pc`,
  206행)는 `_run_pk_range_chunk` 함수 **지역 변수**였다(모듈 최상단 alias 아님). 698행(모듈 레벨)에서
  그대로 재바인딩하면 import 시점에 `pc` 가 정의돼 있지 않아 NameError 로 모듈 로딩 자체가 깨진다.

  → 원안 그대로는 실행 불가능한 지시였다고 판단해, 같은 목표(단일출처·이름 유지·기존 테스트
  무수정 통과)를 달성하는 대안으로 구현했다:
    def _select_direct_rep_axis(axis_counts, axis_coverage):
        from services.exact_diff import pk_range_chunk as pc
        return pc.select_deterministic_rep_axis(axis_counts, axis_coverage)
  이 파일 자체가 이미 전역에서 지역 import 관례를 쓰고 있어(206행·1475행 등 12곳 이상 동일 패턴)
  이질적인 방식이 아니다. 함수 이름·시그니처·반환값은 지시서와 완전히 동일 — 테스트 임포트
  경로(`from routes.agg_diff_route import _select_direct_rep_axis`)도 무수정으로 그대로 통과한다.
