  유효 workflow_token 발급 후, 같은 토큰으로 두 그룹에 /single/save 직접 POST.

  - G_PG  : postgresql 로 방언 바인딩된 그룹
  세션 방언(src_db/tgt_db 의 db_type) = postgresql.

결론
────────────────────────────────────────────────────────────────────────────────────────────
  Before(게이트 없음): oracle 그룹 저장이 방언으로 차단되지 않음(409 DIALECT_MISMATCH 부재).
  After (게이트 있음): oracle 그룹 저장 → 409 DIALECT_MISMATCH 로 저장 자체 거부(식별자 미발급).
  회귀            : 같은 방언(postgresql) 그룹은 두 서버 모두 방언 차단 없음(게이트 통과).
                    → 게이트는 '방언'으로만 판정하며 정상(동일 방언) 등록 흐름을 막지 않음.

  metadata REGISTER_FAILED 는 Before/After·A/B 양쪽에 동일하게 나타나는 게이트 무관 하류 단계로,
  방언 판정 결론에 영향을 주지 않는다(HTTP 본문에 sources 미포함 → 단일 Source metadata SKIP).
