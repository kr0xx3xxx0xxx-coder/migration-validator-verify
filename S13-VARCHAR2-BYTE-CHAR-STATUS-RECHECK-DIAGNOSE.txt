0. 결론 요약
================================================================================
S13(BACKLOG 원문)이 지목한 "오라클이 CHAR_LENGTH만 읽고 CHAR_USED는 전혀 조회 안 한다"는
서술은 이제 사실이 아니다(이미 2026-07-30 8dd4f95에서 해소, S13 등록일 2026-07-29 다음날).
그러나 S13이 실제로 우려하는 것("사용자가 보는 후보추천/컬럼선정 판정이 캐릭터셋 축소
위험을 반영하는가")은 지금도 미해소다. F14/F15는 이 우려와 코드는 공유하지만(같은
_evaluate_compatibility 함수) 도달 지점이 다르다 — 사용자 화면이 아니라 숨김 진단 패널
(#csrPreviewDetails, display:none)에서 끝난다. 즉 (a)완전해소도 (c)완전 무관도 아닌
(b) 부분 해소이며, "부분"의 경계가 BACKLOG 원문이 짚은 지점과 정확히 일치하지 않는다
(원문이 짚은 좁은 문제는 풀렸지만, 더 넓은 실질적 문제가 남아 있다).

1. build_tgt_column_meta_query 재검증 — S13 원문 서술은 지금 사실인가
================================================================================
services/db_adapters/oracle.py:290 build_tgt_column_meta_query, :244 다중테이블 버전
둘 다 6·7번째 컬럼으로 char_used / data_length 를 조회한다(코드 직접 확인, 2026-08-06
현재 상태). 8번째 컬럼(nullable)까지 F14에서 추가돼 있다.

  SELECT column_name, data_type,
         CASE WHEN data_type IN ('CHAR','VARCHAR2','NCHAR','NVARCHAR2')
              THEN char_length ELSE NULL END,
         data_precision, data_scale,
         CASE ... THEN char_used ELSE NULL END,     ← S13이 "없다"고 한 그 컬럼
         CASE ... THEN data_length ELSE NULL END,
         nullable
  FROM all_tab_columns WHERE UPPER(table_name) = :1 ORDER BY column_id

→ 판정: S13 원문의 이 문장은 **stale(2026-07-30 8dd4f95 커밋으로 이미 해소)**. F14는
  이 조회 자체를 고친 게 아니라(이미 돼 있었음), 이 값을 실제 운영 파이프라인까지
  전달하는 provider 배선을 신설한 것(3절 참고).

3-1. 유일한 운영 진입점은 POST /csr-preview → 숨김 디버그 패널
--------------------------------------------------------------------------------
routes/csr_preview_route.py 헤더 주석(원문 그대로):
  "Real Provider 연결 원칙 금지(NullProvider 효과 — metadata/stats=None) — 단, F14
   (VARCHAR2 실효수용량 경고)로 Oracle 한정 예외를 둔다."
  "기존 auto_selected 변경 금지 (이 route는 /analyze 후보 선택에 영향 없음)"
provider_mode 필드도 "null" 고정이고, Oracle 예외를 타려면 호출부가 src_conn/tgt_conn 에
db_type=oracle 접속정보를 **명시적으로** 실어 보내야 한다(안 보내면 기존과 동일하게
NullProvider → tgt_meta=None → _evaluate_compatibility 가 348행 진입 전에 즉시
UNKNOWN_COMPATIBILITY 로 반환, 수용량 비교 자체가 실행되지 않음).

이 route 의 유일한 소비처는 ui/tabler_renderer.py 의 #csrPreviewDetails 인데, F14 보고서
스스로 명시한 대로 접힌(<details>) display:none 개발자 진단용 패널이다("▸ 후보추천
미리보기 (NullProvider 기반 · 참고용)"). 오늘 코드 재확인 결과도 동일(2926행).

  잔여 D. MSSQL 실효수용량 비교 — F15가 명시한 "후속 과제"(MssqlMetadataProvider,
