문제 2 — 재이관 요약 '0건' 모순 (핵심)
────────────────────────────────────────────────────────────
[실측] /agg-diff/prepare → total_reimport_pks=10, /agg-diff/pk-records → 10건,
       상세 Grid 10건, 그룹 분포(D03 5·D06 5) 모두 정상. '요약 카운트'만 0 이었다.
[근본원인] 소규모 재이관 prepare 는 non-stream 경로(표시전략 DIRECT_STREAM_COMPARE)를 탄다.
  이 경로(prepare_reimport_pk_index)는 reimport 총계만 세고, STREAM 경로와 달리
  counts 에 missing_migration/value_mismatch 를, basis 에 source_count/target_count/ratios 를
  저장하지 않았다. pk-records READY 응답이 이 값을 0/null 로 읽어 결과확인 요약이
  '재이관 대상 0건 · 목적 미존재 0 · 값 불일치 0 · 전체 건수 복원 불가'로 오표시.
  → 오늘 오전의 store 소멸(dd455c0)과는 다른 경로다. store 는 파일영속(True)이라 정상이었고,
    이번 건은 store 부재가 아니라 non-stream prepare 의 head 저장 스키마 누락이 원인.
    (dd455c0 의 자동 재-prepare 는 그룹 드릴다운·전체목록 모두 _mvPkEnsurePrepared 로 이미 태우고
     있어, 이 경로에도 적용돼 있었다 — 이번 결함과는 무관.)
[수정] non-stream 경로를 STREAM 과 대칭으로: 목적부재/값불일치 분리집계 → counts·summary·basis 저장,
  source_count/target_count 는 라우트가 COUNT 값 전달(미전달 시 조회 키 수 폴백), ratios 저장.
  저장 레코드/판정/정렬(numeric_pk 미변경) 불변 — 요약 표시만 복원.
  파일: services/exact_diff/agg_contribution.py, routes/agg_diff_route.py
