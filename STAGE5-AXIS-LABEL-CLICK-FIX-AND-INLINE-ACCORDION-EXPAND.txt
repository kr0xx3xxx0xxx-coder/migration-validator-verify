1. 1번 항목 — "GROUP BY 축" 축 이름 클릭 시 예상 밖 동작의 근본원인(실측 확정)
════════════════════════════════════════════════════════════════════════
지시서 가설(옛 클릭 바인딩 잔재)은 **사실이 아니었다**. 실 브라우저에서 축 이름 셀과 그룹 값
셀을 각각 실좌표로 정밀 클릭하고 /agg-diff/prepare 요청 payload 를 캡처해 대조한 결과:

  [before · 축 이름 셀(1번째 td) 클릭]
    scope = {"col":"STATUS_CD","val":"A","pairs":[["STATUS_CD","A"],["DEPT_CD","D01"]]}
    gb_cols = ["STATUS_CD","DEPT_CD"] · source_count = 100
  [before · 그룹 값 셀(2번째 td) 클릭]
    scope = {"col":"STATUS_CD","val":"A","pairs":[["STATUS_CD","A"],["DEPT_CD","D02"]]}
    gb_cols = ["STATUS_CD","DEPT_CD"] · source_count = 100

즉 두 클릭은 **완전히 같은 경로**(각 셀에 별도 onclick·a 태그·리스너 없음 →
`<tr onclick="_mvStage5OpenGroup(i)">` 하나)를 타며, 그룹 조건(scope·pairs)도 클릭한 행 그대로
정확히 전달되고 있었다. 축 이름 텍스트에 남은 옛 바인딩은 존재하지 않는다(그리드 전체에서
"GROUP BY 축" 헤더를 만드는 지점도 _mvStage5PaintGroupList 단 1곳뿐임을 소스로 확인).

진짜 원인은 **결과 렌더 분기**였다. ui/tabler_renderer.py `_mvRiApply` 의

    var _useGroupView = !_isTO && !_hasUserFilter && window._mvRiShowFullDetail !== true
                        && !_earlyStop && _hasGb && (preparing || _reimpN >= 1);

가 `window._mvPkScope`(= 사용자가 이미 그룹 1건을 고른 상태)를 전혀 보지 않는다. 그래서 그룹을
고른 뒤에도 자동 전체추출 시절의 1차 드릴다운 화면 `_mvRiRenderGroupView(d)` 가 그대로 살아,
서버가 gb_cols 전체에서 고른 **대표축** 기준으로 다시 그룹핑한 분포를 그렸다. 실측 재현:

  [before] 축 셀 클릭 후 화면 = 대표 GROUP BY(DEPT_CD) 불일치 분포 / "전체 재이관 대상 100건"
           표 헤더 = [그룹값(DEPT_CD), 불일치 건수, 비율, 대표 PK]   ← 레코드가 아니라 재그룹 요약

클릭한 그룹은 STATUS_CD=A & DEPT_CD=D01 인데 화면은 그와 무관한 대표축(DEPT_CD) 기준 재그룹핑
이라, 사용자가 겪은 "REGION_CD 를 눌렀는데 STATUS_CD 분포가 나온다 + 전체 101건" 과 정확히 같은
증상이다(101 은 레코드 수집 상한 근처 값으로, '전체' 라벨과 겹쳐 더 오해를 키웠다).

조치 — 옛 설계의 잔재이므로 그 경로를 **그룹 1건 화면에서만 차단**했다(축 이름은 이제도 행
클릭 대상이지만, 클릭하면 §2 아코디언으로 그 그룹의 레코드가 정확히 펼쳐진다).
  · `_mvRiApply`      : `var _scopedGroup = !!(window._mvPkScope && window._mvPkScope.col);`
                        를 두고 `_useGroupView` 에 `!_scopedGroup` 추가 → 곧바로 레코드 상세
                        Grid(PK 선두) 렌더. PREPARING·레코드 0건 분기도 scope 를 포함하도록 확장.
  · `_mvRiApplyProgress`: 폴링 중 '잠정 분포' 갱신(_gvMode)도 같은 기준으로 제외(깜빡임 방지).
  · scope 없는 전체추출·기존 결과 보기 경로는 조건을 하나도 바꾸지 않았다(무회귀).

[after 실측] 축 셀 클릭 후: hasRepAxisView=false, 표 헤더 =
  [불일치 유형, ID(PK), STATUS_CD, STATUS_CD, DEPT_CD, DEPT_CD, AMT, AMT] → 그 그룹의 실제
  불일치 레코드(원본/목적 별도 열)만 표시. 값 셀 클릭도 동일(각자 자기 행의 그룹).
