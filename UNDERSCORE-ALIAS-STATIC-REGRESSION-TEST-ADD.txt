[작업 개요]
오라클 ORA-00911(비인용 식별자 '_' 시작 금지) 재발방지를 위해, SQL 생성기가 방출하는 SQL 에
'비인용 밑줄 선두 별칭(AS _x)'이 없는지 검사하는 정적 회귀 테스트를 신규 추가했다.
프로덕션 코드는 일절 수정하지 않았다(신규 테스트 파일 1개만 추가). 브라우저 검증 불필요(순수 정적).

[추가 파일] (1개)
  tests/test_underscore_alias_oracle_regression_static.py

[검출기]

        D1) 문자열/f-string 리터럴의 'AS _x' (직접 조립 SQL) — docstring 예시는 제외
        D2) sqlglot .as_("_..") / alias_(x, "_..") (모듈상수·'+' 좌항 해소 포함 → hash_bucket __HB 도 포착)
