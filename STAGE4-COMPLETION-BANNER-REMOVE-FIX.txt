■ 요청 내용

개별검증 화면에서 아래 세 영역을 코드까지 완전히 삭제한다.

  ① 4단계(통계검증 실행) 완료 후 뜨는 안내박스
     "⚠ 통계검증 실행 완료 · 불일치 있음 (불일치)" 제목 줄
     + 불일치 그룹 요약 문장
     + 전체그룹/일치/값불일치/원본단독/목적단독 5칸 요약 표
     + "결과 확인(5단계) 보기" 버튼

  ② 5단계 상단 처리시간 표시 줄
     "· 5단계 통계검증 실행(상세 추출 별도): 0.95초"
     (계측 자체는 남겨도 되고, 이 위치의 표시만 제거)

  ③ 5단계 상단 실행 이력 요약 박스
     "목적지 테이블: MV_CSPK_TGT / 실행 이력 수: 0 / 차이 없음: 0 / 차이 있음: 0 /
      오류: 0 / 차이 그룹 합계: 0 / 최근 실행: — / 아직 실행 이력이 없습니다."

  공통 조건: 공유 계산 로직은 건드리지 않고 렌더 부분만 제거, 빈 공백 잔류 금지.


■ 결론

세 영역 모두 제거를 완료했고, Oracle 라이브 DB 로 운영 서버(포트 8000)에서 1~5단계를
실제로 클릭해 before/after 를 대조 실측했다. 판정 PASS.
관련 테스트 서브셋을 baseline 과 대조한 결과 신규 회귀 0건이다.

■ "결과 확인(5단계) 보기" 버튼이 유일한 이동 수단이었는가 (요구사항 3번)

아니다. 제거 전(before) 실측에서 확인했다.

  before 실측 결과: "5단계_이동_다음버튼_가능": true
    → 삭제 전 상태에서도 하단 커맨드바 [다음 ▶] 버튼(data-mv-fn=_mvNavStep, args=[1])만으로
      4단계 → 5단계 이동이 정상 동작했다.
  after 실측에서도 같은 버튼만으로 5단계 진입에 성공했다(자동 탭 이동 정책은 종전대로 없음).

따라서 이번 삭제로 5단계 접근 경로가 끊기지는 않는다. 다만 실행 직후 "결과를 보러 가라"는
시각적 유도(콜 투 액션)는 사라지므로, 사용자는 하단 [다음 ▶] 또는 상단 5단계 탭을 직접 눌러야 한다.
이는 요청의 의도(안내박스 제거)에 따른 결과이며 삭제는 그대로 진행했다.
