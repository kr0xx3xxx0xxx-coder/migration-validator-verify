    style(ui): COUNT SQL 접힘 토글 제거·라벨 들여쓰기·박스 높이 2배·복사 버튼 제거 (COUNT-SQL-SECTION-COLLAPSE-INDENT-HEIGHT-COPY-REMOVE-FIX)
    
    2단계(COUNT 사전검증) 화면의 COUNT SQL 섹션을 정리한다.
    
    - 'COUNT SQL 보기 (원본 · 목적지)' 토글(details.mv-sql-fold + summary) 제거 →
      상시 노출 섹션(.mv-count-sql-section)으로 교체. 토글 헤더가 쓰던 세로 공간도 회수
      (결과 Grid 하단~SQL 2열 상단 간격 146px → 100px, 빈 여백 미발생).
    - 원본/목적지 COUNT SQL 라벨 들여쓰기 10px — 규칙 하나
      (.mv-count-sql-grid .sql-hdr h3 + --mv-count-sql-label-indent)로 두 라벨에 동일 적용.
    - SQL 박스 높이 기존의 정확히 2배 — 자연 높이 74.625px(2줄 기준) → min-height 149.25px
      (--mv-count-sql-box-h). max-height/overflow 강제 없음(긴 SQL 자연 확장 유지).
    - 복사 버튼 2개와 인라인 클릭 핸들러(onclick=copySQL('cntSrcBox'/'cntTgtBox')) 제거.
      전역 copySQL 은 통계검증 SQL preview(srcBox/tgtBox)가 계속 쓰는 공용 함수라 존치.
    
    실측(내부망 PostgreSQL 페어, 브라우저 before/after): 토글/복사 버튼 0, 들여쓰기 양쪽
    10px 동일, 박스 149.25/74.63 = 2.000배, COUNT 타일 7개·값·게이트 카드·하단 액션 무변,
    신규 pageerror 0.
