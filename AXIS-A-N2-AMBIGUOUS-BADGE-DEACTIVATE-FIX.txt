1. 배경 / 문제
────────────────────────────────────────────────────────────────────────
진단(AXIS-A-NONE-VS-FALSE-MISCLASSIFICATION-DIAGNOSE) 결과, evaluate_admin_audit_crosscheck 의
axis_a(값 판정)가 None 을 두 하위 케이스로 합쳐서 돌려줌:
  · N1 = 값 자체가 미배선
  · N2 = 값은 있으나 타임스탬프가 아님(A축 관할 밖)
이 둘을 구분하지 않고 B=False + A=None + group_by 를 일괄 NOT_AUDIT_AMBIGUOUS 로 판정 →
SCHOOL_CATEGORY('중등/고등/초등') 같은 정상 저카디 업무코드(GROUP BY 기본추천 컬럼)에도
'⚠ 관리컬럼 미확인' 배지가 붙는 모순 실측(기본추천 + 경고 병기).

2. 수정 내용 (services/candidate_subtype_service.py 단일 파일)

verdict 매핑의 B=False + A=None + group_by 분기(구 754행)만 값 배선 여부로 세분화:
  · N1 (_candidate_sample_values(candidate) is None) → NOT_AUDIT_AMBIGUOUS (배지 유지)

    도달하지 않음(회귀 위험 없음).
  · axis_a 계산(742행) 미변경 → axis_a_available(= axis_a is not None)의 의미도 불변.
    따라서 test_sample_values_wiring.py:300-301, test_admin_column_comment_hypothesis.py:110
    (모두 B=True 경로) 영향 없음 → 갱신 불필요(재실행 통과 확인).

N1/N2 판별 근거: _candidate_sample_values(candidate) 는 값 미배선 시 None, 배선 시 리스트 반환.
이 분기 도달 시점엔 axis_a 가 이미 None 이므로, 값이 배선(non-None)됐다면 그 값은 '타임스탬프가
아니어서 None'이 된 것 = 정확히 N2.
