         그것을 순차 반복하므로 그 위(60초×3세트)를 덮는다.
       · 미지정 액션(COUNT·SQL 생성·나머지 전부)은 속성 자체가 출력되지 않아 기존 20초 그대로 — 무회귀.
       · '영구 고착 방지'라는 타이머 본래 목적은 유지된다(상한이 길어질 뿐 사라지지 않는다).

B-3  가드 차단 시 사용자 피드백                                [ui/tabler_renderer.py:26998-27008 외]

     재시도하면 무반응이라, 사용자가 다른 진입점(원클릭)으로 옮겨가고 그것이 곧 B-1 의 중복 경로였다.
       · 새 UI 컴포넌트를 만들지 않고, 같은 함수가 다른 차단 사유(스키마 오류·접속 해제)에 이미

       · 두 가드를 구분한다: _executeInProgress(진짜 실행 중) / _mvAnyRunActive(다른 실행 중).
       · 기존 '스턱 자기치유' 분기(실제로는 아무것도 진행 중이 아니었던 경우)는 "이미 진행 중"이라고
         말하면 사실과 다르므로 "잔여 상태를 정리했습니다. 한 번 더 눌러 주세요"로 문구를 나눴다.

6. 남는 한계와 위험 (비판적 검토)
════════════════════════════════════════════════════════════════════════
6-1. 클라이언트 가드일 뿐이다
     B-1 은 같은 탭 안에서만 유효하다. 새로고침·다중 탭·직접 API 호출은 여전히 막지 못한다.
     서버측 방어(진단 우선순위 4)는 좀비 표식(비정상 종료 시 해제 누락) 위험 때문에 이번 범위
     밖으로 지정됐고, TTL 또는 generation 연동 해제 설계가 함께 필요하다. **미해소로 남는다.**

6-2. B-1 가드가 넓게 잡힌다(의도된 것이지만 부작용이 있다)
     _mvAnyRunActive() 는 재이관 상세 추출(PREPARING) 진행 중에도 true 다. 따라서 통계검증이
     끝난 직후 40~53초 동안은 원클릭 전체검증도 막힌다. 이는 runExecute 가 이미 갖고 있던 동작과
     같아지는 것이지만, 사용자 입장에서는 "완료됐는데 왜 안 되지"로 보일 수 있다.
     완화책: 이번 A-1 라벨이 "상세 추출 별도"라고 알려주고, B-3 알림이 사유를 말해준다.
     잔여 상태가 잘못 남아 영구 차단되는 경우는 runExecute 의 기존 자기치유 분기가 회수한다.

6-3. 180초는 근거 있는 추정치이지 실측 상한이 아니다
     서버 문 상한 60초 × 최대 3세트를 덮는 값으로 잡았다. GROUP BY 3축 + 보강(pair) 세트까지
     동시에 쓰는 조합은 이번에 실측하지 않았다. 그 경우 180초를 넘길 수 있고, 넘기면 수정 전과
     같은 팝업이 뜬다(더 늦게 뜰 뿐). 상한을 env/설정으로 빼지 않은 것은 지침 범위 밖이기 때문이다.

6-4. B-2 는 '고착 발견'이 느려진다
     통계검증 액션에 한해, 진짜 네트워크 스톨로 프로미스가 영영 미해결일 때 버튼이 풀리는 데
     20초가 아니라 180초가 걸린다. 대신 그 사이 버튼은 '실행 중…'으로 정확히 표시되며,
     이는 정상 실행 중에 팝업이 뜨는 기존 오작동보다 낫다는 판단이다.

6-5. 실측 회차
     A·B-2·B-3 은 50M 조건에서 before/after 각 1회, B-1·1축은 1M 조건에서 각 1회다.
     타이밍 절대값(22.5~23초, 71.9~76.0초)은 실행마다 흔들리므로 단일 수치로 인용하지 말 것.
     판정에 쓴 것은 절대값이 아니라 이산 사실(팝업 유무 / 알림 유무 / 요청 건수 / 표시 문구)이다.

6-6. B-1 실측에 관측용 개입이 있었다
     §2-5 에 적은 대로 (a) 서버 공통 실행 라우트 요청을 '기록 후 차단'하는 fetch 래퍼,
     (b) alert 를 가로채 시각·문구만 기록하는 래퍼, (c) 수정 전 상태가 선행 게이트 다이얼로그에
     막혀 판정이 흐려지지 않도록 게이트 통과 플래그 선설정 — 세 가지를 관측판으로 넣었다.
