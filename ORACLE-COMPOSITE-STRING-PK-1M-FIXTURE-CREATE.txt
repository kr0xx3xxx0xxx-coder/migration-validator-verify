1. 생성 결과 — 실제 행수
────────────────────────────────────────────────────────────────────────
  구분   테이블                 실제 COUNT(*)    기대        판정
  원본   NXDNP.MV_CSPK_SRC      1,000,000        1,000,000   PASS
  목적   NXDNP.MV_CSPK_TGT        990,000          990,000   PASS
  → 누락 10,000행 · 목적지 적재율 99.00%

  PK 형태
    원본 복합 PK (REGION_CD VARCHAR2(4) 문자 + SEQ_NO NUMBER)
         REGION_CD 고유값 1,000종 · MIN 'A001' / MAX 'Z038'
         SEQ_NO 1~1,000 (리전당 순번)
    목적 단일 문자 PK  PK_STR VARCHAR2(20)
         = REGION_CD || '-' || LPAD(SEQ_NO,6,'0')
         MIN 'A001-000001' / MAX 'Z038-000999' · 고유값 990,000

  누락 규칙(결정적·재현 가능)
    전역순번 g = (a-1)*1000 + b 에서 MOD(g,100)=0 인 행을 목적지에서 제외
    → 정확히 10,000행, 전 PK 범위에 균등 분포(특정 구간 편중 아님)

4. 개별검증 1~3단계 실 클릭 인식 확인 (4·5단계 미진행)
────────────────────────────────────────────────────────────────────────
  구동: MV_AUTH_DISABLED=1 인프로세스 서버를 별도 포트로 기동(운영 8000 미간섭),
        Playwright 로 실제 버튼/체크박스 클릭. 프로젝트 TESTONLY_REG.
        검증 경로 Oracle_asis → Oracle_tobe 신규 생성 후 접속 성공.

  [1단계 쿼리검토]  처리 3.14초 / 클릭~응답 5.4초
    원본 테이블 NXDNP.MV_CSPK_SRC · 목적 테이블 NXDNP.MV_CSPK_TGT
    입력 컬럼수 6 · 추출 컬럼수 6 · 매핑 6/6 · 조건 없음 · 조인 없음 · 상태 ● 정상
    blocked=false · error=null

  [2단계 COUNT 사전검증]  127.9초(100만행 오라클 COUNT 원본+목적)
    count_status = COUNT_MINOR_DIFF
    원본 1,000,000 · 목적 990,000 · 순 차이 10,000 · 목적지 적재율 99.0%
    배너: "소규모 COUNT 차이 — 통계검증과 Exact Diff 로 실제 누락/과잉/값 불일치를
           확인하세요(차이만으로 종료하지 않음)"  → 차단 아님, [통계검증 계속] 제공

  [3단계 후보 컬럼 선정]  처리 0.29초
    GROUP BY 기본추천: STATUS_CD (70점, 프로파일 기반 고유값 4)
    SUM 기본추천:      AMT(75점), QTY(75점)
    제외 후보 3건(참고/제외 표에 사유와 함께 표출)
      REG_DT   정책상제외 — 그룹 개수 과다(730개 > 상한 60개) + 명칭-값 불일치 경고
      PK_STR   정책상제외 — GROUP BY 진입 근거 없음(저카디 통계·차원 의미 미확인)
      ITEM_NM  정책상제외 — 고카디널리티(고유값 5000)
    상태: ● 정상 · 실행 예정 = COUNT(*) + GROUP BY 1개 + SUM 2개

  → 1~3단계 모두 정상 인식. 콘솔 오류 0건.
  → 지침대로 3단계에서 중단. 4·5단계 클릭 없음.
