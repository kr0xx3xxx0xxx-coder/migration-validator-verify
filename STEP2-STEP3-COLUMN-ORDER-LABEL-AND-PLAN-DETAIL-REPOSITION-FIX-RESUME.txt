    이 정의는 일괄검증 COUNT 그리드 등 다른 호출부도 함께 쓰므로 거기서 순서를 바꾸면
    2단계 밖까지 순서가 바뀐다. 대신 2단계 타일 표시 계층에만 순서/라벨 규약을 두었다:

        var _MV_COUNT_TILE_LABEL = { 'tgt': '목적건수' }
        function _mvCountTileCols(cols)   — 공유 정의를 타일 순서로 재배열(비파괴)
        function _mvCountTileLabel(col)   — 타일 전용 라벨
    규약에 없는 field 는 뒤에 원래 순서대로 붙는다(향후 컬럼 추가 시 누락 방지).
  · 값 계산 로직 무수정 — field↔값 매핑은 그대로이고 순서/라벨만 바뀐다.
    _mvCountRows() / 판정(_mvStatusIcon) / processing_ms 포맷 전부 불변.
