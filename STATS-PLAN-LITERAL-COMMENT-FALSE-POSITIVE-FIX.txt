1. 배경 / 결함
────────────────────────────────────────────────────────────────────────
근거: verify 저장소 SQLGLOT-USAGE-CONSISTENCY-AUDIT-DIAGNOSE.txt (P2-2)

services/stats_validation_plan_service.py 의 classify_unsupported_sql_shape()가
원본 SQL 텍스트를 전처리 없이 그대로 정규식 검사했다. 이 때문에
  - 문자열 리터럴 안 : 'UNION ALL 처리분', 'SELECT DISTINCT / EXISTS ( 문구'
  - 라인 주석 안     : -- WITH tmp AS ( SELECT ... )
  - 블록 주석 안     : /* GROUP BY DEPT_CD, SUM() OVER (PARTITION BY X) */
같은 텍스트가 실제 구문으로 오인됐다.

오탐의 파급: classify_unsupported_sql_shape() 결과는 _generate_for_snap()의
하드 게이트(services/stats_validation_plan_service.py:784~ )에서
plan_status="UNSUPPORTED" 조기 반환으로 이어지므로,
정상 이관 SQL인데도 통계검증 계획 자체가 생성되지 않았다
(source_sql_preview / target_sql_preview 모두 빈 문자열).
