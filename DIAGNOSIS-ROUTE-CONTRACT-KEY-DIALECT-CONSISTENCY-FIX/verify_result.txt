    BEFORE(HEAD)     접속=postgresql  chunk_key dialect=(미전달→기본 postgres)          match_key dialect=(미전달→기본 postgres)
    AFTER(작업트리)      접속=oracle      chunk_key dialect=oracle                     match_key dialect=oracle
    AFTER(작업트리)      접속=postgresql  chunk_key dialect=postgres                   match_key dialect=postgres

── [4] 기능적 귀결 — 전달된 dialect 로 실제 렌더되는 NULL probe SQL ──
    dialect=postgres  → SELECT 1 FROM NXDNP.MV_ORA_XDIFF_SRC WHERE ID IS NULL LIMIT 1
    dialect=oracle    → SELECT 1 FROM NXDNP.MV_ORA_XDIFF_SRC WHERE ID IS NULL FETCH FIRST 1 ROWS ONLY
    · BEFORE 는 오라클 접속에도 postgres 로 렌더 → 'LIMIT' 포함=True → 오라클 실행 시 ORA-03049 계열 실패 → chunk_key 확정 불가
    · AFTER 는 oracle 로 렌더 → 'FETCH FIRST' 포함=True

── [5] PostgreSQL 회귀 확인 ──────────────────────────────────────────
    PG 접속의 실효 방언: BEFORE=(미전달→기본 postgres) / AFTER=postgres → 동작 동일: True
    (미전달 시 기본값이 'postgres' 이므로 PG 경로는 수정 전후 같은 SQL 이 렌더된다)
