    M17 — 목적 미존재/값 불일치 주황 강조가 화면에 뜨지 않던 결함.
      실측 결과 서버 /agg-diff/pk-records 응답은 정상이었다(tgt=null, diff_cols=[AMT] 모두 채워짐).
      실제 원인은 클라이언트 CSS 충돌 — 5단계 결과표가 table.mtbl 이고 전역 규칙
      `.mtbl td{... color:var(--text)!important}` 가 _mvPkCellSplit 이 td 인라인으로 준
      color:#C2410C 를 덮어써 font-weight 만 남았다(굵지만 검은 글씨).
      판정 로직(missing/isDiff)은 그대로 두고, 같은 파일의 기존 형제 헬퍼
      (_mvPkCellHtml·_mvPkCell2)가 이미 쓰는 span 강조 관례로 마크업만 맞춘다 — 새 CSS 없음.

      aria-expanded=false)를 공통 헬퍼 _mvRemoveAllScopePanels 로 뽑아 두 호출부
      (_mvToggleRowAggDiff·_mvToggleRowExactDiff)에서 재사용한다.
