1. 요청 요약 / 배경
════════════════════════════════════════════════════════════════════════
- 목적: E1(2단계 COUNT 불일치 안내) LLM 간접 활용 기능(MV_COUNT_MISMATCH_LLM_GUIDE_ENABLED,
  기본 OFF)을 위한 자체호스팅 LLM 서빙 준비. 고객사가 Docker 대신 Windows 네이티브,
  인터넷 미연결(폐쇄망) 환경일 수 있다는 전제로 실제 설치·반입 절차를 개발 PC에서
  선행 검증했다.
- 이 작업은 코드 저장소(nxDTV) 수정이 아니라 docs 문서화 + 로컬 설치 실측이다.
  코드 변경은 이미 존재하는 analyzer/ollama_count_mismatch_llm_explainer.py 를
  대상으로 실제 Ollama 서버가 응답 가능한지 확인하는 인프라 준비 성격.
