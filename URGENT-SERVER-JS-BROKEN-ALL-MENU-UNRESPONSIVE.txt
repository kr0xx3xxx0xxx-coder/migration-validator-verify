작업명 : URGENT-SERVER-JS-BROKEN-ALL-MENU-UNRESPONSIVE
✅ 작업 완료 - 렌더 JS 주석 내 '*/' 조기종료로 전체 <script> 파싱 실패(전 메뉴 무반응) → 주석 수정으로 즉시 복구, 실 브라우저 정상 확인 + 재발방지 가드 추가

[정확한 원인]
- 증상: 모든 메뉴 클릭 무반응, 콘솔 'Uncaught ReferenceError: mvToggleGroup is not defined', URL /# 고정.
- 근본원인: BATCH-VALIDATION-SEQUENTIAL-EXECUTION-AND-BLOCKING-HTTP-FIX 에서 추가한 UI 헬퍼
  _mvAwaitBatchExecTerminal 의 주석 문구 'RUNNING_*/STOP_REQUESTED' 중 '*/' 가 JS 블록주석(/* ... */)을
  '조기 종료'시켰다. 그 뒤 한글 텍스트('STOP_REQUESTED 는 진행 중...')가 실행 코드로 해석되어
  SyntaxError: Unexpected identifier '는' 발생(ui/tabler_renderer.py 렌더 결과 blk1.js:7534).
- 파급: 인라인 <script> 블록은 하나라도 문법오류면 '블록 전체'가 파싱 실패한다. 따라서 그 블록 안의
  mvToggleGroup(정의는 tabler_renderer.py:6952 에 멀쩡히 존재), runWrapperValidation, showTab 등 모든 함수가
  '미정의'가 되어 onclick 핸들러가 전부 'is not defined' → 전 메뉴 무반응, 해시 라우팅도 죽어 URL /# 고정.
- 서버/백엔드는 정상: HTML 은 서버가 정상 렌더(그래서 대시보드는 보임). 파이썬 import·기동 정상, 로그에
  크래시/트레이스백 없음. batch_single_core_wrapper.py / validation_scheduler.py / route 문법오류·초기화 실패 없음.
  즉 '클라이언트 JS' 문제이지 서버 다운이 아니었다.
