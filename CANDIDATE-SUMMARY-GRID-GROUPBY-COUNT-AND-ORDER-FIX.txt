── 원인 ────────────────────────────────────────────────────
- 3단계 '후보추천 요약' 그리드(_mvRenderCandidateGrid)가 GROUP BY/SUM 을 _mvPickTop(첫 후보
  '하나')으로만 표시했다. 데이터 출처도 candidate_recommendation 의 top 이라 실제 체크박스
  선택 상태와 무관했다.
- 그래서 체크박스로 GROUP BY 2개(STATUS_CD·DEPT_CD)를 선택해도 그리드 GROUP BY 열엔
  하나(DEPT_CD ↔ DEPT_CD)만 나오고 STATUS_CD 가 누락됐다.
- 즉 그리드가 참조하는 데이터 소스(_mvPickTop of recommendation)와 실제 체크박스 상태
  (_collectCheckedCols)가 서로 달랐던 것이 근본 원인.

── 수정 내용 ───────────────────────────────────────────────
(1) 전체 표시 + 출처 단일화
  - 데이터 출처를 실제 체크박스(_collectCheckedCols)로 단일화. 체크박스가 있으면 라이브 선택을
    그대로 반영(체크박스 없을 때만 추천→pool 폴백).
  - 선택된 GROUP BY/SUM 후보를 '전부' src ↔ tgt 쌍으로 ', ' 나열
    (예: "STATUS_CD ↔ STATUS_CD, DEPT_CD ↔ DEPT_CD"). SUM 도 동일 방식(여러 개 시 전부).
  - 긴 나열은 tooltip 으로 전체 표시(groupByTip/sumTip).
(2) 열 순서 변경
  - "원본|목적|쿼리검토|COUNT|SUM|GROUP BY|상태" → "원본|목적|쿼리검토|COUNT|GROUP BY|SUM|상태"
    (GROUP BY 를 SUM 앞으로).
(3) 실시간 반영
  - refreshFinalSelectionState(체크/해제마다 호출)에 요약 그리드 재렌더 호출 추가
    → 체크박스 선택/해제가 즉시 그리드에 반영.
  - 표시 전용 — 판정/집계/payload/SQL 생성 로직 불변.
