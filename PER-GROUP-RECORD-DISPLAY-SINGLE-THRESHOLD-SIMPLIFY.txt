작업명 : PER-GROUP-RECORD-DISPLAY-SINGLE-THRESHOLD-SIMPLIFY
✅ 작업 완료 - 그룹당 표시 3단계(P1/P2 대표20건/P3)를 단일 기준 2단계(≤100 전부 / 초과 숫자만)로 단순화, 역전 현상 제거·실측/회귀 전부 PASS

[배경 — 없앤 모순]
- 기존 3단계(P1 전부 / P2 대표 20건 / P3 숫자만, 경계 100/1,000)에는 '역전 현상'이 있었다.
  · ~100건: 최대 100건까지 전부 표시
  · 101~1,000건: 오히려 대표 20건만 표시
  → '불일치가 더 적을 때 더 많이 보여주는' 모순.
- 이를 없애기 위해 '대표 20건 표시(P2)' 개념 자체를 제거하고 단일 기준으로 최종 단순화.

[단순화 내용 — 확정 규칙]
  ~100건    : 정확히 찾은 만큼 '전부' 표시(P1)
  100건 초과 : 100건까지만 세고 멈춤 → "100건 초과, 정확한 수는 확인 안 함(조기중단)" 숫자만 + Excel(P3)
- '보여주는 개수'와 '조기중단(세어보는) 상한'을 단일 값으로 통일: early_stop_abs = full_list_max + 1 (기본 101).
- 설정 상한(HARD CAP) 500 유지. 사용자가 99999 입력해도 저장 시 500으로 자동 하향.
