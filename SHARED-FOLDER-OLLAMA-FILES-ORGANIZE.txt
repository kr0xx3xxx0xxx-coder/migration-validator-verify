════════════════════════════════════════════════════════════════════════
1. 요청 요약 / 배경
════════════════════════════════════════════════════════════════════════
- Ollama 는 nxDTV 전용이 아니라 X:\Projects\ 하위 여러 프로젝트가 재사용할 수
  있는 인프라 성격 설치물이므로, 특정 프로젝트(nxDTV) 폴더 내부가 아니라
  형제 폴더로 분리해 관리한다.
- 최초 용도는 nxDTV 의 E1(COUNT 불일치 원인 가이드) LLM 연동이지만, 폴더
  구조 자체는 향후 다른 프로젝트가 같은 Ollama 서비스·모델을 재사용하는
  것을 전제로 설계했다.

2. 실행 내역 (실측, 2026-08-11)
════════════════════════════════════════════════════════════════════════
- X:\Projects\_shared\README.md 신설(12:31 생성, 932 byte) — _shared 폴더의
  존재 이유(프로젝트 비종속 공유 인프라)와 하위 폴더 관례(각 프로그램은
  자기 하위 폴더 안에 관련 파일을 전부 모아둔다)를 명문화.
- X:\Projects\_shared\ollama\ 하위 구조:
  · installer\OllamaSetup.exe        — 설치 파일(1.46 GiB)
  · manifests\...\gemma3\4b          — 모델 메타데이터 ([[OLLAMA-GEMMA-INSTALL]])
  · manifests\...\llama3.2\3b        — 모델 메타데이터 ([[OLLAMA-LLAMA32-3B-INSTALL]])
  · blobs\                           — 두 모델 가중치·설정 blob 12개(총 ≈5.0 GiB)
  · ollama_serve.log                 — 서비스 기동/추론 로그(설치·검증 증적 원본)
- 실측 폴더 총 용량: 6.5 GiB(blobs 5.0G + installer 1.5G + manifests 8K)
- OLLAMA_MODELS 환경변수를 이 경로(X:\Projects\_shared\ollama)로 지정해
  Ollama 서버가 실제로 이 폴더를 저장소로 인식·사용 중임을 서버 로그로 확인
  (routes.go:1933 server config 로그의 OLLAMA_MODELS 값 일치).

3. 코드 저장소 영향
════════════════════════════════════════════════════════════════════════
X:\Projects\_shared\ 는 nxDTV git 저장소 바깥(형제 폴더)이므로 코드 저장소에는
아무 변경사항이 없다(git status 무영향, .gitignore 대상 자체가 아님). 순수
파일시스템 정리 작업.
