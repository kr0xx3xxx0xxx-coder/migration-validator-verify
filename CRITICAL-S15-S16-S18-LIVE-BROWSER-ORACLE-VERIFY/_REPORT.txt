    배너 노드 #fmtBanner(ui/tabler_renderer.py:2601)는 DOM 에 존재하는데 화면에 표시되지

4. 코드와 다르게 동작한 것 — 정직한 정리
════════════════════════════════════════════════════════════════════════
(1) [S15] 화면 "허용 0분 초과" vs 실제 설정 5초.
    허용치를 조건 없이 분 단위 반올림한다(tabler_renderer.py:16445).
    운영 기본값 1800초에서는 정상 표시되므로 실사용 영향은 낮다.

(2) [S16] 지침에 적힌 조합(통계검증 실행 중 원클릭 전체검증)으로는 409 가 발동하지 않는다.
    두 경로의 in-flight 키가 다르기 때문이며, 설계상 의도된 동작이다.
    S16 이 실제로 막는 조건(같은 /execute 중복)에서는 409 가 정확히 작동한다.

(3) [S16] 정상 조작 경로에서는 사용자가 409 문구를 볼 수 없다.
    클라이언트가 버튼을 "실행 중…"으로 비활성화해 선행 차단하기 때문이다.
    409 응답을 화면 알림으로 보여주는 경로는 이번 실측에서 확인되지 않았다.

(4) [S18] hang 유발 SQL(real)이 오류가 아니라 success=true 로 통과한다.
    서버 정지는 막았으나, 문법상 잘못된 SQL 이 화면상 정상으로 진행된다.

(5) [S18 부수] 지침 원문 SQL 입력 시 "1단계 계산 중..." 무한 고착 + 오류 배너 미표시.
    1단계에만 잔여 청소 코드가 없다(2·5단계에는 있음).

(1)~(5) 모두 이번 지침이 "코드 수정 없음"이므로 수정하지 않았다.
