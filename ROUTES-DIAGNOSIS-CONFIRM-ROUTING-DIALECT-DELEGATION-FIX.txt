■ 지시 3 — KEY_RANGE 도달 지점의 __BKT/__RNG ORA-00911 (확인만, 수정 안 함)
- HEAD 커밋본(key_range.py, __BKT 별칭)으로 생성한 SQL 을 실 오라클에 직접 실행 → 재현됨:
    SELECT ... WIDTH_BUCKET(ID, 1, 250001, 8) AS __BKT FROM NXDNP.MV_ORA_XDIFF_SRC GROUP BY ...
    → ORA-00911: _: invalid character after AS
- 단, 현재 작업 트리에는 다른 세션이 진행 중인 미커밋 변경(별칭 __BKT/__RNG → KR_BKT/KR_RNG,
  services/diagnosis/{strategies/key_range.py, strategies/router.py, multi_scope.py} + 관련 테스트)이
  올라와 있어, 이번 라이브 실행([4] After 의 KEY_RANGE 8개 bucket 일괄집계)은 그 미커밋 수정이
  적용된 상태에서 성공했다. 즉 오라클 KEY_RANGE 가 '버킷 일괄집계까지' 정상 동작한 것은
  이번 커밋(07cd4d0)만으로는 보장되지 않으며, 별칭 수정이 커밋되어야 확정된다.
  (이번 커밋만 적용될 경우: KEY_RANGE 전략 도달은 확정, 버킷 일괄집계는 ORA-00911 후 기존
