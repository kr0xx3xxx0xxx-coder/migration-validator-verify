1. 왜 COUNT-only 결과는 "펼칠 행"을 안 만드는가 — 정확한 코드 지점
────────────────────────────────────────────────────────────────────────────
근본 원인은 프론트엔드 한 곳의 조기 return 이다. 백엔드가 막는 게 아니다.

(1) 5단계 결과 메인 렌더 renderExecute(r, targetId, opts)
    - ui/execute_result_renderer.py:770
    - COUNT-only 이면 정상 결과표를 그리기 전에 조기 분기:
        if (_isCountOnlyResult(r)) { renderCountOnlyResult(el, r); return; }
      → ui/execute_result_renderer.py:844-845
    - 이 return 때문에 결과표 렌더(그룹 행 data-row-key 생성)와
      _mvLoadScopeActions(:1393) 가 아예 실행되지 않는다.

(2) COUNT-only 판정
    - _isCountOnlyResult(r): gb_keys 비었고 val_cols 가 전부 COUNT alias
    - ui/execute_result_renderer.py:657-661

(3) COUNT-only 전용 렌더 renderCountOnlyResult(el, r)
    - ui/execute_result_renderer.py:662-711
    - 그리는 것: 판정 배너 + stat 카드 4장(원본COUNT/목적COUNT/차이/판정)
      + 단건 Excel 링크 + 증적 패널(_buildExecEvidencePanel) + 메타
    - 조립 라인 :710  el.innerHTML = banner + cards + excelHtml + 증적 + meta
    - :709 주석 명시: "가상 그룹/일치율/그룹상세표/일치행 보기 없음"
    - 결론: 클릭 가능한 tr[data-row-key] 가 DOM 에 단 하나도 없다
      → 재이관 드릴다운 진입 트리거 자체가 존재하지 않는다.

(4) 드릴다운 진입은 오직 '행 클릭'에서만 열린다
    - 그룹 행 클릭 배선 _mvMakeRowClickable / _mvWireRowsFromCache
      : ui/tabler_renderer.py:16320, 16336-16347
    - 실제 패널 오픈 _mvToggleRowAggDiff(tr, act, r)
      : ui/tabler_renderer.py:16538, scope 를 tr 의 data-row-key(GROUP BY 키)에서 추출(:16544-16555)
    - 즉 GROUP BY 결과 행이 없으면 클릭할 대상이 없다.

(5) 비교 근거: SUM-only(GB0+SUM)는 이미 동작
    - "전체합계" 총계 행이 렌더되어 scopeCol/scopeVal='' 로 빈 scope 드릴다운이 열린다.
    - 실측 스크립트: scripts/dev_e2e/reimport_drilldown_stale_plan_gb0_sumonly_verify.py
    - 반면 COUNT-only(GB0+SUM0)는 그 "전체합계" 행조차 없어 진입점이 0개.

────────────────────────────────────────────────────────────────────────────
2. 백엔드는 이미 scope-optional — 재이관 엔진 그대로 재사용 가능
────────────────────────────────────────────────────────────────────────────
"PK만 있으면 그룹 없이 전체 불일치를 뽑는" 데 필요한 백엔드 변경은 사실상 0 이다.
아래 함수들이 이미 gb_cols=[], sum_cols=[], scope_col='', scope_val='' 를 정상 처리한다.

  - _derive_row_sqls_wrapped(pr, query_full, dialect)
    : routes/exact_diff_route.py:89
    : 원본 이관 SELECT 를 통째로 (SELECT * FROM (원본) mv_reimport_src) 로 감싸 파생.
      CTE/JOIN/UNION wrapping 담당(_reimport_source_needs_wrapping: agg_diff_route.py:650).
      scope/group_by 를 전혀 참조하지 않는다.
  - _pk_resolve(req) : agg_diff_route.py:675 (wrapping 호출 :684-688)
  - _derive_row_compare_cols(...) : agg_diff_route.py:763
    : parse_result.insert_cols/select_items 기반 → GB/SUM 선택과 무관하게 전 컬럼 compare_cols 산출.
  - prepare_reimport_pk_index_stream(...) : services/exact_diff/agg_contribution.py:430
    : gb_cols = [g for g in (gb_cols or []) if g] (:464) → 빈 리스트 허용
      값 불일치 판정은 GB/SUM 이 아니라 compare_cols 로 독립 수행(:479-514)
      레코드 scope = {...} or None (:528) → scope=None 이 정상값
  - prepare_reimport_pk_index(...) DIRECT : agg_contribution.py:169 (동일하게 빈 gb 허용)
  - _pk_agg_sql(...) : agg_contribution.py:94 (GB 0개 SQL 생성)
  - store._where(kind, scope_col, scope_val) : services/exact_diff/store.py:272
    : if scope_col: 가드 → scope 미지정이면 필터 미적용
  - store.page_records(...) : store.py:321
    : unfiltered=(not kind and not scope_col) 경로로 전체 불일치 레코드 그대로 페이징
  - GET /agg-diff/pk-records : agg_diff_route.py:991 (빈 scope 로 전체 목록 반환)
  - POST /agg-diff/prepare : agg_diff_route.py:793 (대량→비동기 job, 소량→직접)

HOLD 는 오직 "키 부재"일 때만 발생한다(MATCH_KEY_HOLD: agg_contribution.py:472-474,
HOLD_UNSUPPORTED_SHAPE: agg_diff_route.py:806-808). scope 없음이 HOLD 사유인 곳은 없다.
→ 설계 원칙("PK 완전부재만 빼면 불일치까지 보여준다")과 정확히 부합한다.

[재사용성 — 핵심]
  - _mvPkLoadPage (tabler_renderer.py:16864) 는 수정 불필요:
    렌더는 uid+'_wrap' 컨테이너에만 의존(:16865), scope_col/scope_val 을 빈 문자열로
    넘기면 전체 테이블 재이관 목록을 조회(:16877-16879). 인자 tr/act 는 재귀 페이징·aria
    용도라 null/{} 로도 동작.
  - 이미 GB0/SUM-only 방어 로직이 들어있음(:16902-16932,
    [COUNT-ONLY-PLAN-STALE-PLAN-DRILLDOWN-BUG]/[...-GB0-SUMONLY-FIX] 주석) → 재사용 안정성 높음.
  - PREPARING 폴링(493bf7b)·display tier(D1~D4)·조기중단·엑셀 내보내기 모두 자동 상속.

[UX 게이트 원칙]
  - COUNT 일치(isMatch)면 버튼 미노출(펼칠 불일치 없음).
  - PK 완전부재면 버튼은 노출하되 클릭 시 _mvPkEnsurePrepared 가 HOLD(MATCH_KEY_HOLD)
    사유를 패널에 그대로 표출 → 설계 원칙의 "아주 안 되는 경우"를 정직하게 안내.
  - COUNT 게이트(치명적 불일치·force-proceed) 상태면 기존 _mvGateBlocked 경고 재사용.
