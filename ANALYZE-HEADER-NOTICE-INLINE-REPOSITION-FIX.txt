2. 구현 내용
════════════════════════════════════════════════════════════════════════
[A] 공용 shell 에서 안내 요소 제거 (ui/tabler_renderer.py ~L2370)
    단계 탭(#mvStepNavBar) 바로 위에 있던
      <div id="mvAnalyzeScopeNotice" style="display:none;text-align:right">
        <div class="analyze-info-banner" ...>…</div>
      </div>
    블록을 통째로 삭제하고 주석만 남겼다. 요소 자체가 사라지므로 그 자리의 여백도 함께 사라진다
    (요구사항 ⑤ — placeholder 를 남기지 않는 이 프로젝트의 SubNav 규칙과 동일한 처리).

[B] 페이지 Header action 영역으로 이동 (_MV_PAGE_HEADERS.analyze)
    기존:  analyze: { title:'개별검증', subtitle:'SQL 1건 임시 분석·확인(보조 도구)', badge:'검증' }
    변경:  analyze: { title:'개별검증', badge:'검증',
                      actions: '<div id="mvAnalyzeScopeNotice" style="text-align:right;
                                 font-size:.8rem;color:#6b7280;line-height:1.5">…</div>' }
    · 부제 키를 제거 → 부제 DOM 자체가 렌더되지 않는다(요구사항 ①).
    · renderPageHeader 는 이미 `display:flex; justify-content:space-between` 구조라
      제목(좌) / actions(우)가 한 행에 배치된다(요구사항 ②).
    · class="analyze-info-banner" 를 떼어냈다 → 그 클래스의 CSS(배경 #f0f6ff, border-left
      3px solid #3b82f6, padding 9px 14px, border-radius 7px, 모두 !important)가 적용되지
      않는다. 인라인 스타일에도 배경·테두리·padding 을 두지 않아 '텍스트만' 남는다(요구사항 ③).
    · onclick 중첩 따옴표는 이 파일의 기존 관행대로 &#39; 엔티티를 사용했다
      (JS 문자열 조기 종료 방지 — 파일 내 다수 선례 존재, L17414 주석에 관행이 명시돼 있다).
      innerHTML 파싱 시 &#39; → ' 로 복원되므로 브라우저 DOM 상의 링크 마크업은 종전과 동일하다
      (실측: outerHTML = <a href="#" onclick="showTab('batch');return false"><strong>[일괄검증]</strong></a>).

[C] renderPageHeader 정렬 보정
    부제가 없으면 제목이 한 줄뿐이라 flex-start 정렬 시 우측 안내가 제목 위쪽에 붙어 어긋난다.
      var _align = subtitle ? 'flex-start' : 'center';
    부제가 있는 페이지(일괄검증 등)는 종전 flex-start 그대로 — 회귀 없음.

[D] 표시 토글 코드는 그대로 유지
    _mvShowStepNavBar / _mvHideStepNavBar 의 #mvAnalyzeScopeNotice 토글은 삭제하지 않았다.
    이 요소는 이제 analyze Header 안에만 렌더되어 다른 화면에서는 getElementById 가 null 이고,
    두 함수 모두 null-safe 이므로 무해하다. 방어 로직을 남겨 기존 계약 테스트도 유지된다.

5. 비판적 검토 (위험·한계)
════════════════════════════════════════════════════════════════════════
· [구조] 안내 문구가 공용 shell HTML → JS 설정(_MV_PAGE_HEADERS)으로 옮겨져, 문구 수정 지점이
  HTML 이 아니라 JS 문자열이 됐다. 대신 '개별검증 화면에만 렌더' 가 설정 자체로 보장되어
  owner 기반 토글에 의존하던 표시 조건이 구조적으로 단순해졌다(토글은 방어로만 잔존).
· [잠재 이슈] 좁은 화면에서는 제목과 안내가 한 행을 나눠 쓰므로 안내 문구가 2~3줄로 접힐 수 있다.
  1600px 뷰포트 실측에서는 546px 폭 1줄. 요구사항이 '한 행 배치'이므로 반응형 접힘 규칙은
  이번 범위에 넣지 않았다(추후 필요 시 별건).
· [잔여] .analyze-info-banner CSS 규칙(2곳)은 이제 어떤 요소에도 적용되지 않는 사문 규칙이 됐다.
  선택자 하나가 `#tab-analyze > .mv-tab > div:first-child` 와 묶여 있어 섣불리 지우면 다른
  요소에 영향 가능성이 있어 이번엔 남겼다(표시 결과에는 영향 없음 — 실측으로 확인).
· [보안/설명가능성] 문구·링크만 다루는 표시 변경이라 heuristic·scoring·근거저장 영향 없음.
