    있어 가중치 조정 근거가 없었는데, 이제 code 별 delta 분포를 실측할 수 있다.
  - explainability 누락   : 이번 작업의 목적 자체. 근거가 서버에 남는다.
  - 보안 위험             : 없음(값 샘플·접속정보 미포함, code/label 은 고정 문자열).
  - 테스트 어려움         : 등식이라는 기계적 불변식이 생겨 오히려 검증이 쉬워졌다.
  - 잔여 위험 1: _base_contribution_meta() 가 _base_score_and_reason() 의 분기 조건을 복제한다.
    한쪽만 고치면 code/label 이 어긋난다(점수·등식은 여전히 정상). 두 함수를 나란히 배치하고
    주석으로 동기화 의무를 명시했다. 다음 단계에서 통합하는 편이 낫다.
  - 잔여 위험 2: payload 가 후보당 평균 3~5건 늘어난다(3키 dict). 0 기여 생략으로 최소화했으나
    후보 수가 많은 대형 테이블에서는 응답 크기를 한 번 실측해볼 가치가 있다.
  - 범위 준수: ui/ 파일 0개 수정, 배선 파일 0개 수정, 화면 변화 0.
