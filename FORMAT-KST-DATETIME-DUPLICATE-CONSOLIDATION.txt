작업명 : FORMAT-KST-DATETIME-DUPLICATE-CONSOLIDATION
✅ 작업 완료 - formatKstDateTime 중복정의를 shared utils 단일 정의(UTC 입력 가정)로 통합, tz 없는 UTC 값 9시간 오표시 해소

■ 1. 근본원인 확인 (실측)
  - 두 정의는 같은 inline <script> 전역 scope(tabler_renderer.py:5345 단일 script 블록)에 있다.
    concat 순서: shared_utils → ... → group_master(마지막). function 선언 hoisting 으로
    나중 선언인 group_master 정의가 이기며, shared_utils 의 window.formatKstDateTime 할당조차
    이미 group_master 정의를 가리킨다 = shared_utils 정의는 완전한 죽은 코드였다.
  - 실 브라우저(포트 8000, 인증 ON) 실측 BEFORE:
      [활성 구현] group_master(로컬 가정)
      ISO_Z      '2026-06-11T04:42:32Z'      -> '2026-06-11 13:42:32'
      BARE_UTC   '2026-06-11 04:42:32'       -> '2026-06-11 04:42:32'   ← 9시간 이름
      UTC_SUFFIX '2026-06-11 04:42:32 UTC'   -> '2026-06-11 13:42:32'
      OFFSET     '2026-06-11T13:42:32+09:00' -> '2026-06-11 13:42:32'
      EMPTY      ''                          -> '-'
