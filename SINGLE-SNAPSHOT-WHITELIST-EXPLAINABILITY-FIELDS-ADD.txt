마법사 5단계의 표시 판정은 ui/execute_result_renderer.py:1030 의 _rvDowngrade 로 결정되는데,

  - 마법사 5단계  : "값 변환 감지 · 확인 필요"(주황 경고)
  - 향후 현황판(스냅샷 재조회) : "일치"(강등 없음)
로 서로 다르게 보일 위험이 있었다. 한글 컬럼명 표기의 출처인 column_comment 도 같은 이유로
스냅샷에 없어, 재조회 화면에서 컬럼 한글명이 사라지는 표기 손실이 있었다.

■ 작업 중 확인된 별개 사안(이번 범위에서 수정하지 않음)
  1) 스냅샷에 total_src / total_tgt 가 없다.
     _rvDowngrade 는 '변환 감지' 외에 '원본/목적 그룹 수(distinct) 실측 불일치'로도 강등되는데,
     그 근거인 total_src/total_tgt 는 result_view 에도 스냅샷에도 저장되지 않는다. 이번 검증
     케이스는 3=3 이라 결과가 갈리지 않았지만, 그룹 수가 다른 run 은 현황판에서 이 갈래의 강등을
     여전히 재구성할 수 없다. 이번 지시는 2필드 추가로 한정되어 손대지 않았고, 현황판 착수 전
     동일한 방식(저장 범위 확장)으로 처리할 후보로 남긴다.
  2) /single/save 의 preset 환원 경로가 sslmode 를 싣지 않는다.
     src_db 를 preset 으로 환원하는 resolve_source_from_conn 결과에 sslmode 가 빠져 있어
     비SSL 인 Inter DB 에서 metadata 수집이 실패하고 등록이 METADATA_BLOCKED 로 막힌다.
     화면과 동일하게 sources 를 명시 전달하면 정상 저장된다(검증 스크립트는 그 경로를 사용).
     이번 작업과 무관한 기존 배선 갭이라 보고만 남긴다.
