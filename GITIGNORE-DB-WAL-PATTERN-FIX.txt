작업명 : GITIGNORE-DB-WAL-PATTERN-FIX

================================================================================
1. 배경 / 문제
================================================================================
.gitignore 에 db/*.db 규칙은 있었으나 SQLite WAL 모드에서 실행 중 생성되는
보조 전이 파일(-shm / -wal)에 대한 규칙이 없었다.
그 결과 db/chunk_checkpoints.db-shm, db/chunk_checkpoints.db-wal 이 매번
미추적(??) 상태로 git status 에 잡혀 잡음을 만들었고,
URGENT-WORKINGTREE-UNCOMMITTED-STACK-COMMIT-RECOVERY 에서
"진짜 미커밋 변경을 가리는 간접 원인" 으로 지적됐다.

================================================================================
2. 수정 내용 (대상 파일: .gitignore 1개)
================================================================================
기존 "# 로컬 SQLite / DB 파일 제외" 블록 바로 아래에 WAL/SHM 보조파일 패턴 추가.
기존 규칙(db/*.db 포함) 및 다른 무관한 규칙은 일절 변경하지 않았다.

패턴 선정 근거:
- *.db-shm / *.db-wal : 저장소 어디에서 생성돼도 동일하게 제외(루트 *.db 규칙과 대칭).
- *.sqlite(-shm/-wal), *.sqlite3(-shm/-wal) : 기존 *.sqlite / *.sqlite3 규칙과 대칭.
- db/ 하위 동일 패턴 : 기존 db/*.db 계열 규칙과 대칭(명시성 유지, 규칙 의도 가독성).
